# From The Fog S3 (Ninjaxx) — Modpack client

Modpack d'horreur **Minecraft 1.19.2 / Forge 43.5.1** (48 fichiers : 46 mods + 2 shaders).

## Installation (méthode simple, recommandée)

1. Installe l'application **[CurseForge](https://www.curseforge.com/download/app)**.
2. Télécharge **[From-The-Fog-S3-1.6.zip](https://github.com/nini17800/from-the-fog-s3-modpack/raw/main/From-The-Fog-S3-1.6.zip)** (ne le dézippe pas).
3. Dans CurseForge : **Minecraft → Créer un profil personnalisé → Importer** (« Import ») → choisis le zip.
4. CurseForge télécharge tous les mods tout seul. Clique sur **Jouer**.
5. Dans Minecraft : **Multijoueur → Ajouter un serveur** → l'adresse que je vous ai envoyée.

> Mets au moins **6 Go de RAM** : CurseForge → Paramètres → Minecraft → Java Settings → Allocated Memory.

## Installation manuelle (sans CurseForge)

1. Installe **[Forge 1.19.2-43.5.1](https://maven.minecraftforge.net/net/minecraftforge/forge/1.19.2-43.5.1/forge-1.19.2-43.5.1-installer.jar)** (« Install client »).
2. Télécharge chaque mod ci-dessous et mets les `.jar` dans `%appdata%\.minecraft\mods`.
3. Mets les 2 shaders (`.zip`) dans `%appdata%\.minecraft\shaderpacks` (facultatif, activables via Oculus).
4. Dézippe le modpack et copie son dossier `overrides/config` dans `%appdata%\.minecraft\config`.
5. Lance le profil **forge 1.19.2** dans le launcher Minecraft.
